## Proyecto Tripleten: Around The U.S. // Constanza Espinoza // Sprint 15

## Proyecto de React + Vite //

En este proyecto se ha utilizado React + Vite para crear una aplicación web.
Este proyecto es un sitio web interactivo, que permite a los usuarios contar con su propio perfil, donde pueden subir fotos, dar like (o desmarcar el like), borrar las fotos, modificar sus datos personales (nombre y ocupación) y cambiar su foto de perfil.
Tecnologías utilizadas:

- HTML: Estructura
- CSS: Diseño
- JAVASCRIPT: Estructura de interactividad
- Git: Control de versiones y actualización
- React: Framework de desarrollo de interfaces de usuario
